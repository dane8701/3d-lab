# 3d-lab

Modèles 3D et sources modifiables pour l'impression.

## Modèles

| Modèle | Fichiers | Description |
| --- | --- | --- |
| [Verre Dane SAMA cannelé](models/verre-dane-sama/) | [STL](models/verre-dane-sama/exports/verre.stl) · [3MF multicolore](models/verre-dane-sama/exports/verre-multicolore.3mf) | Verre creux de 160 mm, avec les inscriptions « Dane SAMA » et « chill with me » en relief. |

Chaque modèle possède ses propres répertoires `src/`, `exports/`, `previews/` et `references/`.

Les fichiers d'impression sont en **millimètres**. Les dimensions déduites de photos sont des estimations ; les vérifications géométriques ne remplacent pas un essai d'impression.

## Ajouter les fichiers au dépôt

Décompresser le ZIP et copier **le contenu du dossier `3d-lab/`** à la racine du dépôt : `README.md`, `.gitignore` et `models/`. Conserver les sous-répertoires pour que les liens et les scripts fonctionnent.

Les exports sont déjà générés. Aucun script n'est nécessaire pour ouvrir les STL ou le 3MF dans un logiciel de tranchage.
